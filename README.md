## ShopList
The Shopping List App is a web application that helps users create, manage, and share shopping lists. It allows users to organize their shopping items, track their progress, set budgets, and manage their personal shopping preferences.

## Features
# 1. Home Page
- View a personalized welcome message.
- See a summary of shopping items, total lists, shared lists, and completed lists.
- Create a new shopping list.
- View all shopping lists.
- Filter lists by all, shared, completed, or archived.
- Sort lists by last updated, name, or category.
- View list details, items, and completion progress.

# 2. Create a Shopping List
- Add a list name and optional notes.
- Select a category: Groceries, Household, Hardware, or Personal.
- Choose a shopping date.
- Add shopping items.
- Set an optional budget.
- Group items by category.
- View a summary before creating the list.

# 3. Share Lists
- Invite people to collaborate on a shopping list.
- View people who have access to a list.
- Share a link to a shopping list.
- Allow editors to invite other people.
- Receive notifications about changes to shared lists.

# 4. Profile Page
- View and update personal information.
- Manage first name, last name, email address, location, and cell number.
- Set currency preferences (ZAR or USD).
- Choose metric or imperial measurement units.
- Enable or disable sorting items by category.
- Change account password.
- Manage two-factor authentication.
- Control shared list activity notifications.
- Enable or disable email tips and inspiration.

# Technologies Used
- React
- TypeScript
- CSS
- Redux for state management
- JSON Server for API and data management

# Install dependencies
npm install
